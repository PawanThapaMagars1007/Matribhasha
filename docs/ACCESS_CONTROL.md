# Cultural access control

| Level | Intended audience |
| --- | --- |
| Public | Anyone, after all publication reviews and required consent are complete |
| Registered | Signed-in users, after publication checks |
| Community | Approved members of the associated community |
| Researcher | Approved researcher role, community researcher membership, or explicit grant |
| Restricted | Explicit active content permission only |
| Not publishable | No audience; remains unavailable |

Unpublished, withdrawn, or unreviewed content is not returned by browse/search routes. Access is checked before serialization. Protected access attempts are logged without placing restricted content in public results. Audio stream routes repeat the access check against cultural media references to prevent direct URL bypass.

Community permissions are scoped to specific content. Only authorized community roles can approve community-scoped reviews or grants. Platform super administrators retain operational access, but publication of sacred/restricted content still requires approved community authorization.
